# Group Tabs to the Right
Group Tabs to the Right is a Chrome extension that does what it says - allows grouping tabs to the right of the active tab you're on.

Release URL: [https://chromewebstore.google.com/detail/bacnbbdofegmaioallmbldnalalgoile/](https://chromewebstore.google.com/detail/bacnbbdofegmaioallmbldnalalgoile/)

# Our Story behind the extension
This extension was developed to take care of one of our annoying issues where we'd have many open tabs but would have to save them all to make room for something else. Usually we'd bookmark the whole tab group but it gets annoying *real quick*. Once we discovered Chrome groups, we started using those. Noticing that there wasn't a way to group tabs at the push of a button (but a way to delete them... hmm...) and considering the fact we were starting to develop Chrome extensions for fun, we decided to make this thing and publish it.
